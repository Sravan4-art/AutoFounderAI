# AutoFounder AI

### AI-Powered Autonomous Startup Business Planner

AutoFounder AI is a Generative AI and Agentic AI-powered platform that transforms business ideas into structured startup plans using multiple specialized AI agents.

## Features

- **Market Research Agent** – Analyzes market opportunities.
- **Competitor Analysis Agent** – Evaluates competitors.
- **SWOT Analysis Agent** – Identifies strengths, weaknesses, opportunities, and threats.
- **Branding Agent** – Generates brand strategies.
- **Finance Agent** – Creates financial strategies.
- **Marketing Agent** – Develops marketing plans.
- **Strategy Agent** – Recommends business strategies.
- **CEO Review Agent** – Evaluates overall business decisions.
- **Investor Agent** – Provides investor insights.
- **Business Plan Agent** – Generates structured business plans.
- **PDF Report Generation** – Exports business reports.

## Technologies Used

- Python
- Streamlit
- Generative AI
- Agentic AI
- Groq LLM API
- SQLite
- ReportLab

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd AutoFounder-AI
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the environment:

   ```bash
   venv\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Create a `.env` file in the root directory:

   ```env
   GROQ_API_KEY=your_groq_api_key
   ```

7. Run the application:

   ```bash
   streamlit run app.py
   ```
